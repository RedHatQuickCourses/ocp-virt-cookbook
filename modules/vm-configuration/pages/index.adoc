= Virtual Machine Configuration
:navtitle:

== Overview

This section covers virtual machine configuration in OpenShift Virtualization, including DNS resolution, remote access methods, node placement control, hotplugging, and VM templates.

== What You'll Learn

Learn how to configure and customize virtual machines in OpenShift Virtualization:

* Internal DNS resolution for VM-to-VM and Pod-to-VM communication
* Remote access methods for Linux and Windows VMs
* Node placement using selectors, affinity, and anti-affinity rules
* Infrastructure component placement on dedicated nodes
* Hotplugging volumes and network interfaces on running VMs
* Creating custom VM templates for repeatable deployments
* How to transfer files between a client and a VM using virtctl, scp and rsync

== Prerequisites

Before working with VM configuration, ensure you have:

* OpenShift {ocp-min-version}+ with OpenShift Virtualization operator installed
* Basic understanding of virtual machines and networking
* Familiarity with YAML syntax
* CLI tools installed: `oc`, `virtctl`, `kubectl`
